## 讀者服務

請使用 GitHub Issues 回報以下事項：

- 書中內容錯誤或過時
- 指令無法執行
- 範例設定需要修正
- 閱讀時遇到的問題
- 建議新增的主題

回報時請盡量提供：

1. 使用的 Hermes Agent 版本
2. 作業系統與執行環境
3. 出問題的章節或指令
4. 完整錯誤訊息（請先移除 API key、token、密碼等敏感資訊）
5. 重現問題的步驟
